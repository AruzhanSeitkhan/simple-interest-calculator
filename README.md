# Simple Interest Calculator

This project calculates simple interest using the principal amount, annual interest rate, and time.

## Formula
Simple Interest = (P * R * T) / 100

Where:
- P = Principal amount
- R = Annual interest rate (%)
- T = Time in years

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 * 5 * 2) / 100 = 100

Total amount = 1100
